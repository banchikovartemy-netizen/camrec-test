# CamRec

CamRec — лёгкая программа видеозаписи для **Linux / Arch Linux**.

## Возможности

- USB-веб-камера и IP/RTSP-камера.
- Опциональная запись звука: микрофон ПК/веб-камеры либо аудиодорожка IP-камеры, если камера её передаёт.
- MP4-записи по сегментам и автоматическое удаление файлов старше заданного количества дней.
- Кнопка **«Сохранить»**: копирует выбранную готовую запись в указанную папку. Если запись не выбрана — сохраняется последняя готовая запись.
- Если нажать **«Сохранить»** во время записи, CamRec предложит остановить её, корректно завершить MP4 и сохранить последний файл.
- При старте записи открывается отдельное окно **«Экран записи»**:
  - ЛКМ — приблизить на 0.2×;
  - ПКМ — отдалить на 0.2×;
  - диапазон зума 1.0×–4.0×.
- Автозапуск записи с выбранного источника.
- Отдельное хранение логина/пароля для IP-камеры.
- Работа через systemd: запись может идти в фоне без открытого интерфейса.

## Установка / обновление

```bash
wget -q https://raw.githubusercontent.com/banchikovartemy-netizen/camrec-test/main/install.sh -O install.sh
chmod +x install.sh
sudo ./install.sh
camrec
```

Архив записей:

```text
/var/lib/camrec/archive
```

## Звук IP-камеры

Звук записывается только если RTSP/HTTP-поток камеры реально содержит аудиодорожку. Если камера передаёт только видео, CamRec запишет только видео.

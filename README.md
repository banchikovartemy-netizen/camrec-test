# CamRec

CamRec — лёгкая программа видеозаписи для **Linux** и **Windows 10/11**.

В корне репозитория находится Linux-версия, а Windows-версия — в папке [`windows/`](windows/).

## Возможности обеих версий

- Веб-камера / USB-камера и IP/RTSP-камера.
- Опциональная запись звука: микрофон ПК/веб-камеры либо аудиодорожка IP-камеры, если камера её передаёт.
- MP4-записи по сегментам и автоматическое удаление файлов старше заданного количества дней.
- Кнопка **«Сохранить»**. Она копирует выбранную готовую запись в указанную пользователем папку. Если запись не выбрана — сохраняется последняя готовая запись.
- Если нажать **«Сохранить»**, пока запись ещё идёт, CamRec предложит сначала остановить её, корректно завершить MP4 и затем сохранить последний файл.
- При старте записи автоматически открывается второе окно **«Экран записи»**:
  - ЛКМ — приблизить на 0.2×;
  - ПКМ — отдалить на 0.2×;
  - диапазон зума 1.0×–4.0×.
- Автозапуск записи с выбранного источника.
- Отдельное хранение логина/пароля для IP-камеры.

## Linux / Arch Linux

Установка или обновление:

```bash
wget -q https://raw.githubusercontent.com/banchikovartemy-netizen/camrec-test/main/install.sh -O install.sh
chmod +x install.sh
sudo ./install.sh
camrec
```

Linux-версия использует `systemd`, поэтому запись может идти в фоне даже без открытого интерфейса. Архив находится в `/var/lib/camrec/archive`.

## Windows 10 / Windows 11

Открой **PowerShell** и выполни:

```powershell
irm https://raw.githubusercontent.com/banchikovartemy-netizen/camrec-test/main/windows/install.ps1 | iex
```

Установщик проверяет Python и FFmpeg, при необходимости пытается поставить их через `winget`, скачивает Windows-версию CamRec и добавляет её в меню Пуск.

В Windows в меню **«Автозапуск…»** можно отдельно включить:

1. автоматическое начало записи при каждом запуске CamRec;
2. запуск самого CamRec вместе с Windows.

## Звук IP-камеры

Звук будет записан только если RTSP/HTTP-поток камеры реально содержит аудиодорожку. Если камера передаёт только видео, CamRec не сможет создать звук искусственно.
